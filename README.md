# Tehran Stations 🚌

A lightweight, fast web client and PWA for Tehran bus stations and live arrival times.

## Why this exists

The official Android app was painfully slow, and iOS users had no native way to check bus arrival times or station schedules. I found the internal API endpoints and transit database, and built a web app.

## Tech Stack

- React 19 + TypeScript + Vite
- MapLibre GL JS + OpenFreeMap
- Tailwind CSS

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Run tests
npm test
```
